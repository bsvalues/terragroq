MIG-20 — the one-owner guard and the recovery it exists to serve, EXECUTED on HERMES.

The review thread on `hermes-ollama-service.ps1:66` said: if `ollama serve` dies while a runner
child survives, every configured retry exits at the name-only guard and the API stays down. The
premise was confirmed and the conclusion was too optimistic. Running the scenario end to end on the
commissioned host found three defects, not one, and the first two hid the third.

  1. THE NAME-ONLY GUARD.  Confirmed exactly as filed.
  2. THE PARENT NEVER RETURNED.  `& $OllamaExe serve *>> $ServeLog` reads the child through a PIPE,
     and the runner child inherits the write end. With the server killed and one runner surviving,
     the task sat in state `Running` for minutes with no listener and no server. There were no
     retries to refuse at the guard, because from Task Scheduler's point of view the task had not
     stopped.
  3. THERE IS NO RESTART-ON-FAILURE FOR THIS SHAPE OF FAILURE.  With the parent fixed to wait on
     PROCESS EXIT, the task correctly went to `Ready` with `LastTaskResult 0xFFFFFFFF` — and
     `RestartCount 3 / RestartInterval 1m` produced NO retry at all, over four minutes. Windows
     applies restart-on-failure to a task that fails to RUN, not to one whose action ran and
     returned a failure code. The `restart_count=3` the record leaned on, and that review reasoned
     about, was never a recovery mechanism.

     A first attempt at (2) also exited 0 — `Start-Process -PassThru` loses `ExitCode` unless the
     process handle is cached, and `exit $null` is `exit 0`. Measured, not reasoned about:
     `LastTaskResult 0`. That is the "reports success while doing nothing" shape, in the file whose
     header claims its task state is a truthful health signal.

Fixed: port-first ownership with process-tree classification and orphan reclamation; wait on process
exit with real file redirection; a non-zero exit whenever the server stops at all; and a two-minute
recheck trigger that is a no-op while healthy and a recovery when it is not.
