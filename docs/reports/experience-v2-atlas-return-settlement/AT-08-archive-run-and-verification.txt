=== copied=0 IS THE HEADLINE, AND IT IS NOT WHAT WAS EXPECTED ===
The continuation expected this run to move ~9.65 GB, on the reasoning that the live store had never
been archived. It moved ZERO BYTES OF BLOB DATA, because all 21 blobs of the live store were ALREADY
in the archive.

That is not the sync having worked. Ollama blobs are content-addressed, and the #997 migration moved
the same content from the container-era store to D:\HermesData\ollama — so those blobs had been
archived back when the store the script pointed at still held them (the log's 2026-08-17 line reads
`OK copied=25 local=25`). The models were protected by an accident of history, not by the mechanism.

What was genuinely NOT protected was the METADATA. The archive held 3 manifests; the live store has
5. A blob with no manifest naming it is not restorable — the exact "unusable-restore condition" the
script's own guard is written against. This run archived the two missing manifests
(llama3.2/3b and snowflake-arctic-embed2/latest) and refreshed a third whose bytes had changed,
copying the superseded copy aside rather than overwriting it.

So the first real archive run's actual product is: the model store is now restorable. It was not
before, and no green log line would ever have said so.
